Hey, I'm Aishwarya 👋
I'm a Computer Science undergraduate at IIIT Vadodara, currently learning cybersecurity by setting things up, testing them, and writing down what I find.

I'm most interested in defensive security, network traffic analysis, and the kind of investigation work done in a SOC. Still learning, still building.
What I've been working on
🛡️ Wazuh SOC Lab
A home lab exploring Windows telemetry and security-event monitoring with Sysmon and Wazuh. I've documented agent setup, event verification, baseline observations, and alert-related evidence.

Repository →
🔎 Tor traffic observation
A beginner Wireshark exercise capturing traffic while using Tor Browser and looking at connections, DNS activity, and TLS-related packets. The capture includes traffic from the machine, so I avoid assuming every packet belongs to Tor.

Repository →
🌐 External web reconnaissance
A documented reconnaissance exercise using Nmap, curl, ping, and nslookup to inspect publicly observable web and network information.
